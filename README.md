# 🤖 LLM Gemini Chatbot

A simple AI chatbot built using **Streamlit** and **Google Gemini API**.

## 🚀 Live Demo
https://llm-gemini-chatbot.streamlit.app

---

## ✨ Features

- AI chatbot using Gemini
- Clean Streamlit UI
- Real-time responses
- Secure API key handling
- Deployable on Streamlit Cloud

- Python
- Streamlit
- Google Gemini API
